五、方案对比

方案优点缺点适用场景
401 触发刷新 + 队列重试实现简单，覆盖所有请求每次失败都要等网络往返通用方案，推荐
请求前检查 Token 过期提前刷新，避免 401 失败多了一次 Token 解码对失败容忍度低的场景
响应头静默续期完全无感，不需要额外请求需要后端配合后端可控的场景
多标签页锁 Token避免并发刷新实现复杂，引入了分布式锁多标签页同时操作的 SaaS
