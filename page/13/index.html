异步编程概述

什么是异步编程

在 JavaScript 中，异步编程是一种编程模式，它允许程序在等待某些操作（如网络请求、文件读取、定时器等）完成的同时继续执行其他代码。异步编程对于构建响应式的用户界面和高效的网络应用至关重要。

JavaScript 是单线程语言，这意味着它一次只能执行一个任务。如果没有异步编程，代码会阻塞在耗时操作上，导致整个应用变得不响应。

JavaScript 异步编程的演进

JavaScript 异步编程经历了以下几个阶段的发展：

  1. 回调函数时代（早期）：使用嵌套的回调函数处理异步操作
  2. Promise 时代（ES6）：引入 Promise 对象，提供了更优雅的异步处理方式
  3. Generator 时代（ES6）：引入 Generator 函数，可以暂停和恢复执行
  4. async/await 时代（ES2017）：引入 async/await 语法糖，使异步代码看起来像同步代码
