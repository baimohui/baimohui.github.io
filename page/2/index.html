本文字数： 3.8k 阅读时长 ≈ 3 分钟

一、什么是合成层

合成层是浏览器渲染过程中的一个概念。当页面元素被提升到独立的合成层时，该元素的绘制不需要与其他元素共享同一个位图，而是由 GPU 单独处理。这使得元素的变换（transform、opacity）动画不需要触发 Layout 和 Paint，大幅提升性能。
