TypeScript 实用类型（Utility Types）

发表于 2026-07-28 分类于 TypeScript
本文字数： 6.9k 阅读时长 ≈ 6 分钟

一、操作对象类型

Partial

将 T 的所有属性变为可选。

Required

将 T 的所有属性变为必选（去掉 ?）。

Readonly

将 T 的所有属性变为只读。

Pick<T, K>

从 T 中选取一组属性 K 组成新类型。

Omit<T, K>

从 T 中排除一组属性 K，保留剩余属性。

Record<K, T>

以 K 为键、T 为值构造一个对象类型。

二、操作联合类型

Exclude<T, U>

从 T 中排除可赋值给 U 的类型。

Extract<T, U>

从 T 中提取可赋值给 U 的类型。

NonNullable

从 T 中排除 null 和 undefined。

三、操作函数类型

ReturnType

获取函数类型的返回值类型。

Parameters

获取函数类型的参数类型（元组）。

ConstructorParameters

获取构造函数类型的参数类型。

InstanceType

获取构造函数类型的实例类型。

四、操作字符串类型

Uppercase / Lowercase / Capitalize / Uncapitalize

五、高级实用类型

Awaited<T

递归解包 Promise 类型（TS 4.5+）。
