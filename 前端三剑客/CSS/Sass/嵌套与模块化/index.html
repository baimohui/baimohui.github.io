二、模块化

@import 已被弃用

@import 的问题：

  • 全局命名冲突——所有变量和 mixin 都暴露在全局作用域
  • 重复导入——多次 @import 同一文件导致重复输出
  • 无私有成员——无法控制哪些内容对外暴露

@use — 模块化方案（推荐）

使用 @use 时，变量必须通过命名空间访问，避免了全局污染。

使用 @use 避免重复编译

对于 @mixin 和 @function 文件，使用 @use 而不是 @import 确保它们只被编译一次，并且不污染全局作用域。
