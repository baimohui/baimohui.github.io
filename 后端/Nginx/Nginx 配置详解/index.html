一、Nginx 是什么

Nginx 是一个高性能的 HTTP 和反向代理服务器，以其高并发、低内存占用和丰富的功能特性成为目前最流行的 Web 服务器之一。常用于静态资源托管、反向代理、负载均衡、HTTPS 配置和 API 网关。

Nginx vs Apache

特性NginxApache
并发模型事件驱动（异步非阻塞）进程/线程驱动
内存占用低（1 万连接约 2.5MB）高（每个连接一个进程）
静态文件极快快
动态内容通过代理转发（不原生支持）内置模块（mod_php）
配置简洁复杂
