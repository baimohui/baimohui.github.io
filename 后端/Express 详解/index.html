一、Express 是什么

Express 是 Node.js 最流行的 Web 应用框架，它基于 Node.js 原生 http 模块构建，在请求响应流程上抽象出中间件机制，使开发者能以声明式的方式组织请求处理逻辑。

Express 识别错误处理中间件的依据是参数个数——当参数个数为 4 时视为错误处理中间件。next(err) 被调用时，Express 跳过后面的所有普通中间件，直接进入第一个错误处理中间件。
