虚拟滚动（Virtual Scroll）详解

发表于 2026-07-28 分类于 性能优化 阅读次数：
本文字数： 6.3k 阅读时长 ≈ 6 分钟

一、什么是虚拟滚动

虚拟滚动是一种长列表优化技术，只渲染当前可视区域内的 DOM 元素，而非渲染列表中的所有数据。无论数据总量多大（数万甚至百万条），页面上始终保持固定数量的 DOM 节点。

为什么需要虚拟滚动

二、核心原理

虚拟滚动的核心思路是用 JS 模拟滚动条，根据滚动位置计算出当前应该显示哪些数据项，只渲染这些项，并利用绝对定位或 transform 控制它们在容器中的位置。

数据量推荐方案原因

九、常见问题

Q1: 虚拟滚动会导致 SEO 问题吗

虚拟滚动渲染的内容在 DOM 中不完整，搜索引擎无法抓取全部数据。需要进行 SEO 的页面（如电商列表）应使用服务端分页替代虚拟滚动。

Q2: 虚拟滚动中如何实现 Ctrl+F 搜索

浏览器的 Ctrl+F 只能搜索 DOM 中存在的文本。虚拟滚动中大部分数据不在 DOM 中，搜索不到。解决方案：

  • 用搜索框组件替代 Ctrl+F
  • 搜索时切换为全量渲染（数据替换为搜索结果）
  • 使用 contenteditable 或独立的搜索索引

Q3: 虚拟滚动能解决内存问题吗

DOM 数量减少了，但 JS 数据仍然全部在内存中。如果数据总量上百万条，JS 对象本身也会占用大量内存。此时需要配合服务端分页，按需加载数据。

十、推荐学习路径

  1. 理解虚拟滚动的原理：固定容器、计算可见范围、只渲染可见项
  2. 用手写实现理解核心逻辑（本文的 React/Vue 实例）
  3. 使用成熟库（react-window / TanStack Virtual）到实际项目中
  4. 处理边缘情况：动态高度、滚动恢复、键盘导航
