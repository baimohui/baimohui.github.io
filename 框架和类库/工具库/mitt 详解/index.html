一、mitt 是什么

mitt 是一个只有 200 字节的轻量级事件发射器（Event Emitter），由 Vue 作者尤雨溪编写。它提供了 on、off、emit 三个核心方法，用于实现模块间的解耦通信。

与其他事件库对比

库体积特性适用场景
mitt200Bon/off/emit，无依赖轻量事件总线
Node.js EventEmitter~8KB完整 API，支持 once/listeners服务端
EventEmitter3~3KB性能优化对性能敏感的 Node 场景
Vue 2 EventBus需引入 Vue依赖 Vue 实例旧 Vue 项目
