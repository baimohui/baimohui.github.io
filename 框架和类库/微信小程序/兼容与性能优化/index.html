一、小程序独有的性能模型

小程序的性能优化和 Web 完全不同，根本原因在于它的双线程架构：

Web 中 JS 和 DOM 在同一个线程，直接修改 DOM 即可。小程序中逻辑层和渲染层完全隔离，每次数据更新需要跨线程通信——JSON 序列化 + 传输 + 解析。这个通信成本是小程序性能问题的根源。
